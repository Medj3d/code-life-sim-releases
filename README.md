# Code-Life-Sim: Downloads

Code-Life-Sim is a learning game: you write real Python code to finish contracts for clients, earn in-game money, buy upgrades and furnish your room.

This repository only holds the downloads. The game is developed in a private repository.

## Download for Windows 10 and 11

- **Installer:** [Code-Life-Sim-Setup.exe](https://github.com/Medj3d/code-life-sim-releases/releases/latest/download/Code-Life-Sim-Setup.exe)
- **Without installer:** [Code-Life-Sim.zip](https://github.com/Medj3d/code-life-sim-releases/releases/latest/download/Code-Life-Sim.zip): unpack it and start `Code-Life-Sim.bat`

You don't need Python; the game brings everything it needs. Both links always point to the newest version.

The installed game updates itself: when it starts, it asks GitHub whether there is a newer version and installs it. The zip version only shows you the link.

Windows may warn about an unknown publisher, because the installer is not signed yet. Click "More info", then "Run anyway". If a freshly set up PC blocks the installer completely, use the zip.
